BeautyCode is the official website for a registered Georgian beauty products company, built to establish their social media presence and support marketing efforts.

Designed with a strong focus on UI/UX, the site is built with React, React Query, Motion for fluid animations, and Tailwind CSS. It includes live chat support for customer engagement.
