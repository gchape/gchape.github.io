An idea doesn't have to become a big application straight away. Sometimes a single useful function, a simple page, or a small script is the right place to start.

## Make the first step useful

Pick the smallest version that does something real. Give it a clear purpose. Use it, notice what feels awkward, and make the next change from there.

```typescript
const idea = {
	start: "small",
	keep: "building",
};

// One useful step at a time.
```

## Leave room to learn

A small project leaves space for experiments. It is easier to try a different approach when the cost of changing your mind is low.

- Give the first version one clear job.
- Make the result easy to understand.
- Keep a note of what you learn.
- Let the next step come from using the thing.

## Finish a little something

There is a quiet satisfaction in getting a small thing to work. It doesn't need every feature on the list. It just needs to be useful enough to exist outside the idea stage.

Start there. See what happens next.
